# 叙事与形式适配

只取当前作品相关的部分。用户指定的体裁、现实承诺和声音优先；不能把所有作品写成论坛长帖，或把诗歌、对白修成规范说明文。

## 虚构与混合创作

明确授权的小说、故事或假设情境，可以创造人物、经历、对白和心理，不必向用户索要现实出处。故事依赖的真实历史、职业、技术等若会改变情节可信度，则核准相关事实；纯架空设定检查内部一致性。混合创作使纪实部分与必要的虚构处理可辨认，避免把对在世真人的严重指控或私密情节包装成真实记录。

- **人物有眼前目标**：他现在想得到什么，为什么要行动，旧办法在哪一步失效，行动付出什么代价。小事也能推动故事；不用每次都设置生死抉择。
- **性格通过选择出现**：谁面前会退让，何时撒谎，擅长什么，又在哪里反复出错。配角也有自己的目的，不只负责递消息或赞美主角。
- **场景造成变化**：结束时，信息、关系、计划、风险、理解或情绪有所推进。氛围与停顿可以有效，不强迫每段都有事件；长时间只有换景和寒暄时，检查场景是否还承担任务。
- **对白做事情**：说服、遮掩、试探、拖延、靠近或保全面子。人物可以答非所问或省略，但不要为了读者轮流朗读双方已知的背景，也别轮流替作者总结主题。
- **细节服从视角**：人物先注意与自身处境有关的东西。近距离视角保护人物当时的知识边界；全知视角转移时保持读者定位。身体、物件、时间、空间和世界规则持续一致。
- **转折有来路**：重要后果尽量来自先前行动、关系和已有规则。新设定与巧合可以使用，却不能反复替人物解决困局；规则例外有伏笔或代价。
- **场景与概述交替**：关键选择和关系变化值得放慢，重复劳动和已知过程可以带过。设定在影响行动时解释，不把开篇写成术语手册。

结尾可停在行动、关系的新位置或无法撤回的后果上。开放结尾可以留结果的余地，仍要完成作品承诺的核心推进。前文物件重现时应有实际作用或理解变化；不用每篇强做首尾呼应或由旁白解释主题。

## 按读者接收方式适配

| 形式 | 重点与边界 |
| --- | --- |
| 问答、评论 | 尽早接住实际问题，解释根据与适用范围；反方来自真实争议，不为空设反转服务 |
| 论坛长帖 | 顺时间、调查或经历推进，可补充和岔话；更新须有真实新进展，不编网友互动或“有人看就继续” |
| 公众号、博客 | 长度来自材料、推理和过程；小标题帮助定位，部分不必等长，标题与正文事实强度一致 |
| 人物、历史、个人叙事 | 时间线用于核对，正文顺理解需要组织；保留真实压力和当时认知，不把履历写成宿命 |
| 新闻、产品、行业解读 | 交代新变化及具体受影响者；资料解读、测试计划、亲测体验各有证据要求 |
| 短文、社交内容 | 集中完成一个主要沟通任务；经授权缩写时重新取舍材料，不必沿长文逐句删词，不强加反转 |
| 教程、方法 | 先让读者知道结果、前提和常见卡点，步骤按依赖排列，每步有动作及可见结果；列表和冒号可正常使用 |
| 评测、商业稿 | 围绕真实任务、过程、失败、结果及适用者展开；区分合作关系、官方信息和作者亲测，不把宣传当观察 |
| 口播、播客、演讲 | 写给耳朵：名词首次说清，指代能跟上，数字突出重点；保护用户要求保留的数据。检查换气与停顿，有实际朗读才报告实测时长，否则标明估计 |
| 剧本、对白 | 主要用可见可听的动作，心理按形式转为行为或台词；允许省略、不完整句和人物各自的口气 |
| 诗歌、抒情、实验写作 | 意象与感受应有关系和变化，分行承担呼吸、重音或意义；允许拟人、排比、非标准句法，不套散文均匀度或标点禁令 |
| 报告、规范、翻译 | 保持专业结构、必要列表、术语、精确数值与引文；自然表达不等于改成闲聊或删掉操作约束 |
| 产品界面文案 | 按标题、动作、状态、错误和恢复路径写；用真实权限与能力界定承诺，详细边界见 `editing-boundaries.md` |

这些是选择方法的提示，不是固定结构。形式转换须有相应编辑授权；校对、润色不因本表擅自改文体。
