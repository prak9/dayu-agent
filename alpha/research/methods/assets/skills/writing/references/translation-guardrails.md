# 翻译与保真改写护栏

忠实首先指信息、逻辑、语气和用途不走样，不等于所有任务都逐行复刻源文版式。开始前选择一种模式；用户的明确要求优先。

## 选择模式

### Structure-aligned

用于合同、规范、论文对照、字幕、逐段审校、保留 Markdown/表格结构，或用户明确要求格式与段落对应的任务。

- 保留标题层级、段落与列表顺序、表格列数、引用层级和有意义的换行。
- 不跨段移动信息；列表项和表格单元保持一一对应。
- 句子可在同一结构单元内拆合，以满足目标语言语法，但不得改变论证顺序或引用归属。

### Natural translation

普通文章、邮件、演讲稿和面向阅读的译文默认使用此模式。

- 保留全部信息、论证顺序、语气强度、条件、例外和不确定性。
- 可为目标语言的连贯性拆合句子；原段落切分妨碍理解时，也可谨慎拆分或合并相邻段落，但不得删去信息、改变观点顺序或混淆说话者。
- 不保留纯粹由页面宽度、OCR 或复制过程产生的断行。列表、表格、代码和引用的语义结构仍需保留。

### Localization

只在用户明确要求本地化、改写式翻译或目标市场适配时使用。

- 可以调整习语、称谓、日期/单位呈现、文化参照和例子，使目标读者获得相近效果。
- 不得静默改变事实、产品行为、法律义务或作者立场；重大适配应可识别，必要时用简短译注说明。
- 用户没有授权的内容仍按 Natural translation 处理。

## 保持信息

- 不新增背景、例子、评价、立场、推断、总结或译者注。
- 不删除事实、数字、限定、否定、因果关系和承载意义的重复。
- 不把正文缩成摘要，不把描述增强为断言，不把相关性增强为因果性。
- 发现原文明显矛盾或疑似错误时，忠实翻译；只有用户要求校订时才另行指出。

## 保护不可改动内容

原样保留以下内容：

- fenced code block、缩进代码块和内联代码；
- URL、email、路径、命令、参数、包名、类名、函数名和变量名；
- 模板占位符、配置键、ID、哈希、版本号和数学公式；
- Markdown 结构符号、链接目标和表格对齐标记。

只翻译 Markdown 链接的可见文字。除非用户要求本地化数值，否则保留精确数字和单位，不擅自换算。

## 处理术语和专名

- 使用目标语言中稳定、通行的译名。
- 没有稳定译名的专名保留原文，不自造译名。
- 技术术语以准确为先；读者可能不熟悉时，可在首次出现处写“译名（原文）”。
- 同一概念使用同一译法。用户提供术语表时，以术语表为准。

## 两遍修订

第一遍按所选模式翻译，核对所有信息点和不可改动内容。第二遍调整词序、句式、连接与必要的段落边界，使目标语言自然，并执行以下检查：

- 行动者、时间、否定范围和指代是否明确；
- 术语是否一致，数字与单位是否准确；
- 是否残留源语言语序、空泛名词化或多余被动；
- 是否误加原文没有的路标、标题、强调或结论；
- 结构变化是否符合所选模式，且没有改变信息顺序或归属。

默认只输出译文，不附分析、说明或自检记录。
